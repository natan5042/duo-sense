# Настройка кассы (чтобы квест и счётчики работали)

## В чём причина: в сцене нет зоны кассы

Скрипт **CheckoutZone** в сцене **quete_croquettes** не висит ни на одном объекте. Поэтому при подходе к кассе ничего не происходит — счётчики (0/2, 0/1 и т.д.) не обновляются.

---

## Что сделать по шагам

### 1. Создать зону кассы

1. Открой сцену **quete_croquettes**.
2. В **Hierarchy** правый клик → **Create Empty**. Назови объект, например, `ZoneCaisse`.
3. Перемести его **перед кассой** (туда, где стоит игрок в коляске у кассира). Position по X/Y выставь так, чтобы зона была на полу перед стойкой.

### 2. Добавить коллайдер-триггер

1. Выбери `ZoneCaisse`.
2. **Add Component** → **Box Collider 2D**.
3. Включи галочку **Is Trigger**.
4. Задай **Size** (и при необходимости **Offset**), чтобы зона **перекрывала место, где стоит игрок у кассы**. Если зона слишком маленькая, игрок может стоять рядом и триггер не сработает. В сцене зона отображается зелёным контуром в редакторе.

### 3. Добавить скрипт CheckoutZone

1. На том же объекте `ZoneCaisse`: **Add Component** → в поиске введи **Checkout Zone**.
2. Оставь **Player Tag** = `Player` (если у твоего игрока тег именно Player).
3. **Counter Display Root** (важно для визуала): создай в сцене **пустой GameObject** перед стойкой кассы (там, где должны лежать продукты). Назови, например, `ProduitsSurCaisse`. Перетащи его в поле **Counter Display Root** у CheckoutZone. Тогда отсканированные продукты будут **переноситься** на этот объект (видны на кассе), а не исчезать. Без этого поля продукты по-прежнему будут удаляться после сканирования.

### 4. Проверить игрока

- У объекта игрока (или у дочернего объекта с коллайдером) должен быть **Tag = Player**.
- На игроке должен висеть скрипт **ItemPickup** (подбор предметов по E). Без него «продукт в руках» не определяется.

### 5. Как считается «продукт на кассе»

- Игра смотрит только на **то, что сейчас в руках** у игрока: у этого объекта в **PickableItem** поле **Item Id** (lait, soupe, eau, croquette, spaghetti).
- **Порядок действий**: подойти к продукту → нажать **E** (взять) → **подойти к кассе и зайти в зону** `ZoneCaisse`. В момент входа в зону с продуктом в руках вызывается «сканирование», счётчик квеста обновляется и предмет убирается из рук.
- Если зайти в зону **без предмета в руках** или с предметом с другим/пустым `itemId`, ничего не произойдёт.

---

## Краткий чек-лист

- [ ] В сцене есть пустой объект перед кассой (напр. `ZoneCaisse`).
- [ ] На нём **Box Collider 2D** с **Is Trigger = true**, размер зоны достаточный.
- [ ] На нём висит скрипт **CheckoutZone**.
- [ ] В сцене есть **SupermarketQuestManager** (на любом объекте).
- [ ] У игрока тег **Player** и скрипт **ItemPickup**.
- [ ] У продуктов в магазине на **PickableItem** указаны **Item Id**: lait, soupe, eau, croquette, spaghetti (как в квесте).

После этого при «входе в зону с продуктом в руках» счётчики в квесте «Acheter les produits» должны обновляться.

### 6. Продукты на кассе и выход из магазина

- Если задан **Counter Display Root**, каждый отсканированный продукт **перемещается** на этот объект (остаётся видимым на кассе), а не удаляется.
- **Store Exit Point** : создай пустой GameObject **у двери магазина снаружи** (на улице) и назначь его в поле **Store Exit Point** у CheckoutZone. Когда все продукты из списка отсканированы и игрок в зоне кассы, **все объекты с тегом Player** телепортируются к этой точке (игроки выходят из магазина).
